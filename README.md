# مركز شباب العبور — نظام إدارة النشاط الرياضي

## ما تم تحسينه
- RTL كامل وخط Cairo.
- نسخ احتياطي مباشر كامل لملف `db.json` من زر واحد، مع نسخ تلقائية دوارة داخل مجلد `backups`.
- طباعة تقارير الحضور والجداول مع `@media print`.
- حضور وغياب حسب تاريخ تختاره، مع حفظ يومي في `db.json`.
- تنبيه ذكي للاشتراكات المنتهية وتلوين اللاعبين غير المسددين بالأحمر.
- أرشيف تلقائي بعد يوم 5 من كل شهر للرياضات واللاعبين الذين لم يجددوا.
- حسابات الصلاحية «مشاهدة + تعديل» يمكنها إضافة وتعديل اللاعبين داخل الألعاب المحددة لها.
- اختيار أكثر من لعبة للحساب من قائمة تحتوي كل الرياضات المسجلة.
- دعم أنواع العضويات الثلاثة فقط:
  1. عضويه عائليه
  2. عضويه شرفيه
  3. العضويه المؤقته (التى بها اقساط)
- إضافة الرقم القومي للاعب.
- Excel import/export.
- PWA وOffline caching وManifest بأيقونات 192 و512.
- معالجة أخطاء الخادم وحفظ ذري للـ `db.json`.
- الجلسة لا تنتهي بعد 30 ثانية؛ تستمر طالما النشاط موجود، مع heartbeat وتجديد آخر ظهور.
- تحسينات Responsive والتنقل والتحديث الديناميكي.

## التشغيل
1. ثبّت Node.js LTS.
2. افتح المجلد.
3. شغّل `run-app.bat` أو نفّذ:
```bash
npm install
npm start
```
4. افتح `http://localhost:3000`.

## بيانات الدخول الافتراضية
- الأدمن: `Fasmo`
- كلمة المرور: `Fasmo123#`

يفضل تغيير بيانات الدخول عند التشغيل الفعلي باستخدام متغيرات البيئة `ADMIN_USER` و`ADMIN_PASS`.

## ملاحظات
- إشعارات المتصفح تعمل عند منح الموقع إذن الإشعارات. الإشعارات Push الحقيقية أثناء إغلاق المتصفح تحتاج إعداد VAPID/Push Provider لاحقاً.
- صور اللاعبين والإيصالات يمكن تخزينها كبيانات مرفقة؛ يفضل في الاستخدام الكبير نقل الملفات إلى تخزين ملفات منفصل ثم حفظ الرابط في قاعدة البيانات.
- عند نمو `db.json` بشكل كبير، الانتقال إلى SQLite سيكون أفضل.
